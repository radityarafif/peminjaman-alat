# Aplikasi Peminjaman Alat

Aplikasi web peminjaman alat berbasis PHP dan MySQL dengan tiga peran: admin, petugas, dan peminjam.

## Cara menjalankan
1. Letakkan folder proyek di `C:\xampp\htdocs\peminjaman-alat`.
2. Jalankan Apache dan MySQL di XAMPP Control Panel.
3. Buka phpMyAdmin, buat database `db_peminjaman_alat`, lalu import `database.sql`.
4. Buka `http://localhost/peminjaman-alat/login.php`.
